# Кессельский сабакк — кантина «Спайс-Ран»

Код проекта размещен в одном HTML-файле и содержит разметку, стили и скрипты для карточной игры кессельский сабакк. Игрок соревнуется с тремя противниками с искусственным интеллектом, применяет жетоны сдвига и механику риска для победы в раундах.

## Особенности проекта

Архитектура одного файла упрощает развертывание. Вся логика, стили и разметка находятся в документе index.html.

Внешние зависимости отсутствуют. Шрифты загружаются через CDN, остальной функционал работает на стандартных API браузера.

Звуковые эффекты и фоновый шум создаются через Web Audio API без использования внешних аудиофайлов.

Прогресс сохраняется в localStorage. Система учитывает кредиты, количество побед и открытые жетоны сдвига.

Применение сетки и flexbox обеспечивает корректное отображение интерфейса на мобильных устройствах и десктопах.

Поведение искусственного интеллекта имеет три уровня сложности: новичок, контрабандист, Ландо.

## Правила игры

1. Цель игры.
1.1. Игрок собирает пару карт с минимальной разницей значений. Разница, равная нулю, считается парой.
2. Состав колоды.
2.1. Колода содержит 44 карты двух семейств: песок и кровь.
2.2. Каждое семейство включает значения от 1 до 6, три карты самозванца и одну карту силоп.
3. Ход игры.
3.1. Раунд длится три хода.
3.2. В свой ход игрок активирует жетон сдвига, берет карту или спасует.
3.3. Взятие карты требует оплаты одной фишки в банк раунда.
3.4. Игрок выбирает карту из закрытой колоды или открытого сброса и сбрасывает карту того же семейства.
4. Особые карты.
4.1. Карта силоп копирует значение второй карты в руке.
4.2. Карта самозванец не имеет фиксированного значения. При вскрытии игрок бросает две кости и выбирает одно из выпавших значений.
5. Вскрытие и расчет фишек.
5.1. Победитель раунда забирает свои вложения из банка.
5.2. Проигравшие теряют вложенные фишки и платят штраф, равный разнице значений их карт.
5.3. Игрок, потерявший все фишки, выбывает из партии.
5.4. Последний оставшийся игрок побеждает.

## Управление

Интерфейс позволяет управлять игрой с клавиатуры.

1. D: взять карту.
2. S: спасовать.
3. 1 или 2: выбрать колоду песка или крови.
4. 3 или 4: выбрать сброс песка или крови.
5. N: активировать способность никса.
6. Пробел: остановить бегунок в мини-игре.
7. Esc: отмена действия или закрытие окна.
8. R: открыть правила.
9. M: переключить звук.
