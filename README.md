= Кессельский сабакк — Кантина «Спайс-Ран» =
Браузерная реализация карточной игры кессельский сабакк. Код проекта размещен в одном HTML-файле, который содержит разметку, стили и скрипты. Игрок соревнуется с тремя противниками с искусственным интеллектом, применяет жетоны сдвига и механику риска для победы в раундах.
== Особенности проекта ==
Архитектура одного файла упрощает развертывание. Вся логика, стили и разметка находятся в документе ''index.html''.
Внешние зависимости отсутствуют. Шрифты загружаются через CDN, остальной функционал работает на стандартных API браузера.
Звуковые эффекты и фоновый шум создаются через Web Audio API без использования внешних аудиофайлов.
Прогресс сохраняется в ''localStorage''. Система учитывает кредиты, количество побед и открытые жетоны сдвига.
Применение сетки и flexbox позволяет корректно отображать интерфейс на мобильных устройствах и десктопах.
Поведение искусственного интеллекта имеет три уровня сложности: Новичок, Контрабандист, Ландо.
== Правила игры ==
Цель игры состоит в сборе пары карт с минимальной разницей значений. Разница, равная нулю, считается парой.
Состав колоды.
1.1. Колода содержит 44 карты двух семейств: Песок и Кровь.
1.2. Каждое семейство включает значения от 1 до 6, три карты Самозванца и одну карту Силоп.
Ход игры.
2.1. Раунд длится три хода.
2.2. В свой ход игрок активирует жетон сдвига, берет карту или спасует.
2.3. Взятие карты требует оплаты одной фишки в банк раунда.
2.4. Игрок выбирает карту из закрытой колоды или открытого сброса и сбрасывает карту того же семейства.
Особые карты.
3.1. Карта Силоп копирует значение второй карты в руке.
3.2. Карта Самозванец не имеет фиксированного значения. При вскрытии игрок бросает две кости и выбирает одно из выпавших значений.
Вскрытие и расчет фишек.
4.1. Победитель раунда забирает свои вложения из банка.
4.2. Проигравшие теряют вложенные фишки и платят штраф, равный разнице значений их карт.
4.3. Игрок, потерявший все фишки, выбывает из партии.
4.4. Последний оставшийся игрок побеждает.
== Управление ==
Интерфейс позволяет управлять игрой с клавиатуры.
D: взять карту.
S: спасовать.
1 или 2: выбрать колоду Песка или Крови.
3 или 4: выбрать сброс Песка или Крови.
N: активировать способность Никса.
Пробел: остановить бегунок в мини-игре.
Esc: отмена действия или закрытие окна.
R: открыть правила.
M: переключить звук.
